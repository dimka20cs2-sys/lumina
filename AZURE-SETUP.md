# Вход через Microsoft в Lumina: настройка приложения Azure

Lumina пускает в игру только с аккаунтом Microsoft, на котором куплена Minecraft: Java Edition.
Для входа через Microsoft лаунчеру нужно собственное «приложение» в Azure. Это бесплатно и занимает около 10 минут.
Чужой client ID (от другого лаунчера) использовать нельзя: так вы выдавали бы себя за чужую программу.

## Шаг 1. Зарегистрировать приложение (бесплатно)

1. Откройте https://portal.azure.com и войдите любым аккаунтом Microsoft.
   Если портал попросит создать каталог или клиент (tenant), согласитесь: это бесплатно.
2. В поиске наверху наберите **Microsoft Entra ID** и откройте его.
3. Слева выберите **App registrations** (Регистрация приложений), затем **New registration**.
4. Заполните поля:
   - **Name**: например `Lumina Launcher`.
   - **Supported account types**: **Personal Microsoft accounts only** (только личные аккаунты Microsoft).
   - **Redirect URI** оставьте пустым.
5. Нажмите **Register**.
6. На странице приложения скопируйте **Application (client) ID**. Он выглядит так: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`.
7. Слева откройте **Authentication**. Внизу, в разделе **Advanced settings**, у пункта
   **Allow public client flows** поставьте **Yes** и нажмите **Save**. Это включает вход по коду (device code).
8. Секрет приложения (**Certificates & secrets**) создавать **не нужно**. Лаунчер — публичный клиент, и секрета у него быть не должно.

## Шаг 2. Вставить ID в Lumina

Откройте **Настройки → Вход через Microsoft**, вставьте Application (client) ID и нажмите **Сохранить**.
Кнопка «Войти через Microsoft» на вкладке «Аккаунт» станет активной.

## Шаг 3. Запросить доступ к Minecraft API у Mojang (обязательно)

Microsoft выдаёт токены любому зарегистрированному приложению. Но сервер Minecraft (`api.minecraftservices.com`)
принимает вход только от приложений, которые одобрила Mojang. Пока одобрения нет, на последнем шаге входа
Lumina покажет ошибку **403 «Invalid app registration»**. Это нормально: приложение создано правильно,
оно просто ещё не в списке разрешённых.

1. Откройте официальную форму Mojang для сторонних лаунчеров: **https://aka.ms/mce-reviewappid**
2. Укажите:
   - Application (client) ID из шага 1;
   - название (`Lumina`) и короткое описание: «лаунчер Minecraft: Java Edition, вход только через аккаунт Microsoft, проверка покупки игры»;
   - ссылку на сайт или страницу проекта, если она есть.
3. Отправьте форму и ждите ответа на почту. Mojang рассматривает заявки вручную, обычно пачками.
   Это может занять от нескольких дней до нескольких недель, и ответа может не быть совсем.
   Повторно отправлять форму без причины не стоит.

После одобрения ничего менять не нужно: просто войдите снова.

## Что происходит при входе

1. Lumina получает у Microsoft короткий код. Вы открываете https://www.microsoft.com/link, вводите код и подтверждаете вход.
   Пароль вы вводите только на сайте Microsoft, лаунчер его не видит.
2. Затем по цепочке: Xbox Live → XSTS → Minecraft Services. После этого Lumina проверяет покупку игры (entitlements) и загружает профиль (ник, UUID).
3. Если игры на аккаунте нет, запуск блокируется.
4. Токен обновления хранится в `%APPDATA%\.lumina\accounts.dat`. Файл зашифрован Windows DPAPI: прочитать его может только ваш пользователь Windows на этом компьютере.
   Кнопка «Выйти» удаляет токены.

## Частые ошибки

| Сообщение | Что сделать |
|---|---|
| «Приложение с таким client ID не найдено» | Проверьте, что скопирован именно Application (client) ID, а не Object ID или Tenant ID. |
| «Не включены public client flows» | Шаг 1, пункт 7. |
| «Приложение Azure должно поддерживать личные аккаунты» | При регистрации выбран не тот тип аккаунтов. Создайте приложение заново с типом «Personal Microsoft accounts only». |
| 403 «Invalid app registration» | Mojang ещё не одобрила заявку (шаг 3). Ждите ответа. |
| «Нет профиля Xbox» | Зайдите на https://www.xbox.com под этим аккаунтом и создайте профиль (бесплатно). |
| «Детский аккаунт» | Взрослый должен добавить аккаунт в семью: https://account.microsoft.com/family |
| «Нет Minecraft: Java Edition» | Игру нужно купить на https://www.minecraft.net |
