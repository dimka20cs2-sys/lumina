Максимальная защита

Безопасность, которой можно доверять

Lumina спроектирована так, чтобы ваш аккаунт Microsoft, файлы игры и сохранения были защищены на системном уровне Windows.

OAuth 2.0 Device Flow

Лаунчер никогда не запрашивает и не видит ваш пароль. Авторизация проходит исключительно в вашем браузере на официальном домене login.microsoftonline.com по одноразовому коду устройства.

Криптография Windows DPAPI

Токены сессии в accounts.dat шифруются системным криптопровайдером ProtectedData (CurrentUser) с уникальной энтропией. Даже при копировании файла расшифровать его на другом ПК невозможно.

Контроль хешей SHA-1 / SHA-512

Каждый файл клиента, библиотека, Java Runtime от Mojang и мод из Modrinth проверяется по криптографическому хешу до запуска. Сетевые соединения работают строго по TLS 1.2 / 1.3 с белым списком доменов.

Изоляция WebView2 + CSP

Интерфейс изолирован на виртуальном хосте https://app.local под строгой политикой Content-Security-Policy без внешних скриптов, телеметрии и фоновых служб, а установщик сам проверяет SHA-256 при распаковке.

Zero Telemetry · Строгий белый список
Сетевая прозрачность: куда обращается Lumina

В исходном коде жёстко зафиксирован список разрешённых доменов (AllowedHosts и PackHosts). Любые сторонние хосты, аналитика, реклама и обход путей (Zip-Slip / Path Traversal) блокируются на уровне ядра.

Частые вопросы

Не нашли ответ? Загляните в инструкцию внутри лаунчера.

Нужна ли лицензия Minecraft?

Да. Lumina работает с официальной Minecraft: Java Edition и входит через аккаунт Microsoft, на котором куплена игра.

Какие версии игры поддерживаются?

Все релизные версии начиная с 1.20. Для каждой версии лаунчер сам показывает, какие загрузчики модов доступны.

Это безопасно? Куда вводится пароль и где хранятся токены?

Пароль вводится только на официальном сайте Microsoft в вашем браузере (протокол OAuth 2.0 Device Code). Сам лаунчер никогда не видит ваш логин и пароль. Токен сессии шифруется системным криптопровайдером Windows DPAPI (CurrentUser) — расшифровать файл accounts.dat на другом компьютере невозможно.

Почему Windows SmartScreen может показать предупреждение при первом запуске?

Lumina распространяется бесплатно без платного коммерческого сертификата подписи кода, поэтому фильтр SmartScreen при первом запуске может показать окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Вы всегда можете сверить контрольную сумму SHA-256 архива в блоке скачивания ниже через команду certutil -hashfile Lumina-1.0.0.zip SHA256.

Что входит в пакет «Оптимизация»?

Проверенные моды для ускорения игры (например, Sodium и Lithium или их аналоги), подобранные под ваш загрузчик и версию. Если для версии нет сборки — мод пропускается, и лаунчер об этом скажет.

Какие системные требования?

Windows 10 или 11 (64-бит), .NET Framework 4.x и Microsoft Edge WebView2 — оба обычно уже есть в системе. Для самой игры желательно от 4 ГБ свободной памяти.

Где хранятся игры и миры?

В папке данных лаунчера. Её можно сменить в «Настройках» и открыть одной кнопкой.
